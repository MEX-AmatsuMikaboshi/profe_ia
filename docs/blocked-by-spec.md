# BLOCKED_BY_SPEC

Registro de decisiones genuinamente necesarias que **ninguna autoridad superior** resuelve
(`Plan.md` §0.2.5). Se resuelven por control de cambios del Maestro (Maestro §0.1.12), nunca
por invención local.

Formato de entrada:

```
BLOCKED_BY_SPEC — [decisión exacta faltante] | tarea afectada | fecha | resolución
```

## Entradas

*(Ninguna. Estado inicial conforme a `Plan.md` §0.3.)*

> Los documentos de autoridad que faltan en el entorno de trabajo **no** se registran aquí:
> son insumos ausentes, no decisiones sin resolver. Ver `docs/plan/PLAN_STATUS.md`.
